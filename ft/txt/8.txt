# 🔹 1. Distribution Plot

```python
sns.distplot(dataset['fare'])
```

### Meaning:

* `distplot` → distribution graph
* `fare` → ticket price

👉 Shows:

* histogram + curve

---

👉 From **page 2 image**:
👉 Most fares are low, few are high (right skewed)

---

```python
sns.distplot(dataset['fare'], kde=False)
```

👉 Removes smooth curve

---

⚠ Note:

```text
distplot is deprecated
```

Use:

```python
sns.histplot()
```

---

# 🔹 2. Joint Plot

```python
sns.jointplot(x='age', y='fare', data=dataset)
```

### Word-by-word:

* `jointplot` → 2-variable plot
* `x='age'` → X-axis
* `y='fare'` → Y-axis

---

👉 From **page 3 image**:
👉 Shows:

* scatter plot
* histogram

👉 Insight:
👉 No strong relation

---

# 🔹 3. Rug Plot

# ✅ 7. CLEAN PYTHON IMPLEMENTATION

```python
import pandas as pd
import numpy as np
import matplotlib.pyplot as plt
import seaborn as sns

dataset = sns.load_dataset('titanic')

sns.histplot(dataset['fare'])

sns.jointplot(x='age', y='fare', data=dataset)

sns.rugplot(dataset['fare'])

sns.barplot(x='sex', y='age', data=dataset)

sns.countplot(x='sex', data=dataset)

sns.boxplot(x='sex', y='age', data=dataset)

sns.boxplot(x='sex', y='age', data=dataset, hue='survived')

sns.violinplot(x='sex', y='age', data=dataset)

sns.stripplot(x='sex', y='age', data=dataset)

sns.swarmplot(x='sex', y='age', data=dataset)

sns.violinplot(x='sex', y='age', data=dataset)
sns.swarmplot(x='sex', y='age', data=dataset, color='black')

plt.show()
```
