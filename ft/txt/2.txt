## 🔹 Outlier Detection

```python
dataset = [11,41,20,3,101,55,68,97,99,6]
```

👉 Sample data

---

```python
sorted(dataset)
```

👉 Sort values

---

```python
quantile1, quantile3 = np.percentile(dataset, [25,75])
```

### Word-by-word:

* `percentile` → find quartiles
* `[25,75]` → Q1 and Q3

---

## 🔹 VERY IMPORTANT (Understand Properly)

### Q1 = 25%

### Q3 = 75%

---

```python
iqr_value = (quantile3 - quantile1)
```

👉 IQR = Q3 - Q1

---

```python
lower_bound = Q1 - 1.5 * IQR
upper_bound = Q3 + 1.5 * IQR
```

👉 Outlier range

---

### Final Meaning:

If value:

```
< lower_bound OR > upper_bound → OUTLIER
```

## 🔹 Data Transformation

---

### Age Calculation

```python
from datetime import date
df['age'] = date.today().year - df['Year_Birth']
```

### Word-by-word:

* `date.today().year` → current year
* `df['Year_Birth']` → birth year

👉 Age = current year - birth year

---

---

### Extract Year

```python
df['Year'] = pd.DatetimeIndex(df['Dt_Admission']).year
```

### Meaning:

* Converts date column → extract year

---

---

### Experience / Years since admission

```python
df['E_L'] = date.today().year - df['Year']
```

👉 Years since admission

---

---

## 🔹 Fees Cleaning

```python
df['Fees$'] = df['College_Fees'].str.replace(',', '').str.replace('$', '')
```

### Word-by-word:

* `str.replace` → remove symbols
* `,` → comma
* `$` → dollar

👉 Convert:

```
$84,835 → 84835
```

---

```python
df['Fees_M$'] = df['Fees$'].apply(lambda X: round(X/1000000))
```

### Word-by-word:

* `apply` → apply function
* `lambda` → small function
* `X/1000000` → convert to millions

👉 Example:

```
84835 → 0 million
```
