## 🔹 MEAN (Average)

```python
import numpy
speed = [99,86,87,88,111,86,103,87,94,78,77,85,86]
x = numpy.mean(speed)
print(x)
```

---

### Word-by-word:

* `import numpy` → math library
* `speed` → list of numbers
* `=` → assign
* `numpy.mean()` → calculate average
* `print(x)` → display result

---

### What is Mean?

Formula:

```
Mean = Sum of all values / Total values
```

👉 Output:

```
89.76
```

---

## 🔹 MEDIAN

```python
x = numpy.median(speed)
print(x)
```

---

### Word-by-word:

* `median()` → middle value

---

### Meaning:

Sorted:

```
77,78,85,86,86,86,87,87,88,94,99,103,111
```

Middle = **87**

---

## 🔹 MODE

```python
from scipy import stats
x = stats.mode(speed)
print(x)
```

---

### Word-by-word:

* `scipy` → scientific library
* `stats.mode()` → most frequent value

---

### Meaning:

👉 Most repeated = **86**

# ✅ 10. CLEAN PYTHON IMPLEMENTATION

```python
import numpy
from scipy import stats
import pandas as pd
from collections import Counter

speed = [99,86,87,88,111,86,103,87,94,78,77,85,86]

print(numpy.mean(speed))
print(numpy.median(speed))
print(stats.mode(speed))

n_num = [1,2,3,4,5]

n = len(n_num)
mean = sum(n_num)/n
print(mean)

n_num.sort()

if n % 2 == 0:
    median = (n_num[n//2] + n_num[n//2 - 1]) / 2
else:
    median = n_num[n//2]

print(median)

n_num = [1,2,3,4,5,5]
data = Counter(n_num)

mode = [k for k, v in data.items() if v == max(data.values())]

print(mode)

df = pd.DataFrame({'A':['a','b','c','c','a','b'],'B':[0,1,1,0,1,0],'C':[7,8,9,5,3,6]})

df['A'] = df['A'].astype('category')

print(df.groupby(['A']).count().reset_index())
print(df.groupby(['A','B']).mean().reset_index())

data = pd.read_csv("Iris.csv")

setosa = data['Species'] == 'Iris-setosa'
print(data[setosa].describe())

versicolor = data['Species'] == 'Iris-versicolor'
print(data[versicolor].describe())

virginica = data['Species'] == 'Iris-virginica'
print(data[virginica].describe())
```
