# ✅ 20. Outliers

Extreme abnormal values.

Detection:

* Boxplot
* IQR

Formula:
IQR = Q_3 - Q_1

Outlier:
x < Q_1 - 1.5(IQR) \quad \text{or} \quad x > Q_3 + 1.5(IQR)

# UNIT 5 — CONFUSION MATRIX & METRICS

# ✅ 42. Confusion Matrix

| Actual \ Predicted | Positive | Negative |
| ------------------ | -------- | -------- |
| Positive           | TP       | FN       |
| Negative           | FP       | TN       |

---

# ✅ 43. TP (True Positive)

Correct YES prediction.

---

# ✅ 44. TN (True Negative)

Correct NO prediction.

---

# ✅ 45. FP (False Positive)

Wrong YES.

---

# ✅ 46. FN (False Negative)

Wrong NO.

---

# ✅ 47. Accuracy

\text{Accuracy} = \frac{TP+TN}{TP+TN+FP+FN}

---

# ✅ 48. Precision

\text{Precision} = \frac{TP}{TP+FP}

---

# ✅ 49. Recall

\text{Recall} = \frac{TP}{TP+FN}

---

# ✅ 50. F1 Score

F1 = 2\left(\frac{Precision \times Recall}{Precision + Recall}\right)
