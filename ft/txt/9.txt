## 🔹 What is a Box Plot?

Box plot = graph showing:

| Part     | Meaning         |
| -------- | --------------- |
| Box      | middle 50% data |
| Line     | median          |
| Whiskers | range           |
| Dots     | outliers        |

---

## 🔹 Why important?

👉 Detect:

* Outliers
* Spread
* Median

# ✅ 4. CORE CONCEPTS (CLEAR)

---

## 🔹 Median

Middle value

---

## 🔹 Quartiles

* Q1 → 25%
* Q2 → median
* Q3 → 75%

---

## 🔹 IQR

```text
IQR = Q3 - Q1
```

---

## 🔹 Outliers

Values outside:

```text
Q1 - 1.5×IQR  
Q3 + 1.5×IQR
```

---

## 🔹 Hue

Extra grouping variable
